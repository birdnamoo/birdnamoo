# UJ · [@birdnamoo](https://github.com/birdnamoo)

Co-Founder & CTO of [**iyulab**](https://github.com/iyulab) — I build manufacturing software for Korean SMEs and an open-source ecosystem of AI infrastructure and developer tooling around it.

### What I build

- **Manufacturing systems** — MES, CMMS, and a local-first ERP/ops platform for manufacturing and logistics SMEs.
- **AI / LLM infrastructure** — agent frameworks and RAG/document pipelines: `ironhive`, `ironbees`, `FluxIndex`, `FileFlux`, `MLoop`.
- **Developer tooling** — local-first apps and libraries: `Textree`, `Declart`, `BareChat`, `cronex`.

### How I think about software

- Local-first and sovereign deployment as a default, not a feature.
- *AI proposes, the filesystem owns.*
- ADR-driven, constitution-style governance for long-lived projects.
- Form-First data modeling (Formology).
- MIT-licensed open-source cores with commercial service tiers.
